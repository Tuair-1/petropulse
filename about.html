About PetroPulse

石化脉动 PetroPulse

一个由 Claude Code 在单次会话中从零生成的石化行业信息平台 —— 用数据可视化与交互设计,把这条纵贯能源与材料的巨型产业链装进一个网页。

◈ 2026-08-01 单次会话生成 ◈ 4 个页面 · 8 幅交互图表 ◈ 42 个产业链节点 ◈ 手绘炼厂夜景 SVG
Why

项目缘起

石化工业与每个人的生活息息相关:汽油、塑料瓶、化纤衣物、轮胎、口罩……但这条产业链极少被完整呈现。 本站的初衷,是以可视化的方式把「原油 → 炼化 → 化工品 → 材料 → 终端」的全链条讲清楚, 同时验证一个命题:AI 能否独立完成一个完整、专业、美观的前端项目。

How

如何构建

从零开始:先搭设计系统(配色 / 字体 / 组件规范),再逐页构建; 手绘炼厂夜景矢量动画、行情跑马灯、交互动画均由原生 SVG 与 CSS 实现; 图表采用 Apache ECharts;全站零构建工具、零框架依赖,托管于 GitHub Pages。

Stack

技术架构

▲ HTML5 语义化结构 ▲ CSS3 设计系统(变量 / Grid / 动画) ▲ Vanilla JavaScript (ES2020+) ▲ Apache ECharts 5.5 ▲ 手绘 SVG 场景动画 ▲ IntersectionObserver 滚动动效 ▲ 响应式布局(桌面 / 平板 / 手机) ▲ GitHub Pages 静态托管
