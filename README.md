# PetroPulse 石化脉动

石化产业智慧信息平台 —— 由 Claude Code 在单次会话中从零生成并部署。

## 页面

| 页面 | 说明 |
| --- | --- |
| `index.html` | 首页:炼厂夜景动画首屏 · 行情跑马灯 · 价格走势 · 产品中心 · 绿色转型 |
| `market.html` | 市场数据:原油/化工品价格、产能分布、景气指数、贸易结构、现货参考表 |
| `chain.html` | 产业链:五层互动图谱(42 节点,点击查看档案) |
| `about.html` | 关于:项目缘起 · 技术架构 · 数据声明 |

## 技术栈

原生 HTML5 + CSS3 设计系统 + Vanilla JS + Apache ECharts 5.5(本地化) + 手绘 SVG 动画,零构建工具,GitHub Pages 托管。

## 声明

站内行情与统计数值均为演示样例,不构成投资建议。
